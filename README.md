# ezupcranes.com

Static website for EZUP Crane Systems.

- `src/` – page content, one file per page
- `products.py` – the product line, defined once (names, text, picture, quote-form option)
- `site/` – the finished website; this is the folder to deploy
- `build.py` – wraps each page in the shared header and footer and fills in the product blocks. Run `python3 build.py` after editing anything in `src/` or `products.py`.

## Product pictures
The product images in `site/assets/img/render/` are 3D renderings, not photographs. They are generated by the scripts in `renders/` (Blender's Python module with the Cycles renderer); see `renders/README.md`. Each picture exists at two widths (`-800.webp`, `-1600.webp`).

In a page, `{{render:ezup-industrial|Alt text|css-class|sizes}}` writes the `<img>` tag with both widths. `<!-- products:ezup -->` writes the product cards for a group from `products.py`, and `<!-- lineup -->` writes the product explorer on the home page.

To swap a rendering for a real photo, save the photo over the two `.webp` files with the same names (4:3, 1600 and 800 px wide) and update the `alt` text in `products.py` so it no longer says "Rendering".

## Crane layout tool (EZUP Cranes page)
`layout3d/layout3d.src.js` is a small three.js model driven by the sliders. It is bundled into `site/assets/layout3d.js` and only downloaded when the section scrolls near. To rebuild after editing:

    npm install three esbuild
    npx esbuild layout3d/layout3d.src.js --bundle --format=esm --minify --target=es2019 --outfile=site/assets/layout3d.js

"Request a quote for this layout" opens the quote form with capacity, span and runway length filled in.

## Fonts
Barlow, Barlow Condensed and IBM Plex Mono (SIL Open Font License) are served from `site/assets/fonts/`, so pages make no request to a font host.

## Deploying (Cloudflare Pages)
1. Push this folder to a GitHub repository.
2. In Cloudflare Pages, connect the repository. Build command: `python3 build.py`. Output directory: `site`.
3. Before moving the ezupcranes.com DNS from Squarespace, copy the existing MX and TXT records so brad@ezupcranes.com keeps working.

## Forms
The quote and dealer forms run without a server today: the visitor gets a formatted copy to email. When the Cloudflare Worker is ready, add `data-endpoint="https://…"` to each `<form>` and requests are posted to it.

## Form delivery (functions/api/request.js)
Quote and dealer forms POST to `/api/request`, a Cloudflare Pages Function that emails the request (Resend) and adds the contact, a note and an ASAP next action in OnePageCRM.
Set these in Cloudflare Pages > ezupcranes-site > Settings > Variables and Secrets (Production):
- `RESEND_API_KEY` (secret), `NOTIFY_EMAIL` = brad@ezupcranes.com
- `ONEPAGE_USER_ID` (secret), `ONEPAGE_API_KEY` (secret) from OnePageCRM > Apps > API configuration
Then redeploy (Deployments > ... > Retry deployment). If a key is missing, the form falls back to showing the visitor a copy to email.

## CPQ (ezupcranes.com/cpq/)
Internal configure-price-quote tool. Browser files in `site/cpq/`, API in `functions/api/cpq/`, shared logic in `lib/`.
Needs, in Cloudflare Pages > ezupcranes-site > Settings:
- Binding: KV namespace, variable name `CPQ`
- Variables: `ACCESS_TEAM_DOMAIN` (e.g. ezup.cloudflareaccess.com), `ACCESS_AUD` (Access application audience tag), `ADMIN_EMAILS` (brad@ezupcranes.com)
- A Cloudflare Access application covering ezupcranes.com/cpq and ezupcranes.com/api/cpq
Every API call verifies the Access token; without these settings the API refuses all requests.
Local test: `wrangler pages dev site --kv CPQ --binding DEV_AUTH_BYPASS=1` (bypass only works on localhost).

## Crane configurator (configure.html)
Customers configure an EZUP Industrial or Professional bridge crane, jib, gantry or monorail, watch a dimensioned drawing (and optional 3D model) follow their input, and get a numbered budget quote with drawing, 3D image, scope, member sizes and terms. Every quote says it is an estimate that must be confirmed by EZUP sales management before an order.

- `lib/craneDesign.js` – sizing and checks (AISC 360 ASD) for every crane type; `lib/shapes.js` holds AISC Shapes Database v15 properties
- `lib/craneDraw.js` – the plan and elevation drawings (SVG)
- `lib/pricing.js` – bill of materials and price (server only); `lib/geo.js` – freight distance from the site ZIP
- `lib/quoteText.js` – the estimate disclaimer and terms printed on every quote
- `functions/api/estimate.js` – price for the live display (no costs leave the server)
- `functions/api/quote.js` – numbers the quote (W26-0001), emails EZUP the full cost breakdown and design checks, adds the lead to OnePageCRM with an ASAP action, and emails the customer when `MAIL_FROM` is a verified sender
- `layout3d/configure.src.js` and `layout3d/cpq3d.src.js` – browser code, bundled to `site/assets/configure.js` and `site/assets/cpq3d.js`:

    npx esbuild layout3d/configure.src.js --bundle --format=esm --minify --target=es2020 --outfile=site/assets/configure.js
    npx esbuild layout3d/cpq3d.src.js --bundle --format=esm --minify --target=es2020 --outfile=site/assets/cpq3d.js   (needs `npm install three`)

### When prices are shown
Costs come from the CPQ price table (Prices & rules tab, stored in the `CPQ` KV namespace); new items appear there unverified.
- On ezupcranes.com a price is shown only when every cost item it uses has been verified in the last 90 days. Otherwise the customer sees "Your budget price will be confirmed by EZUP sales management", and EZUP still gets the full breakdown by email.
- On preview deployments (`*.pages.dev`) sample costs are shown, marked "Preview: sample costs".
- Override with the `PUBLIC_PRICING` variable: `verified` (default), `on`, or `off`.
Margin uses the CPQ target margin (27%, never below 20%); quotes are valid 15 days.
